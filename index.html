Full Deployment Guide

Follow these four simple steps to host your JARVIS backend for free and link your smartphone.

1

Create GitHub Repository

Go to github.com/new and create a public repository named jarvis-phone-assistant.

Clone it to your computer or use GitHub Desktop, and copy all code files generated in the REPO CODE tab into their respective directory paths.

2

Set Repository Secrets & Deploy Backend

In your GitHub repository, go to Settings > Secrets and variables > Actions and add:

  • GEMINI_API_KEY: Your Gemini API Key from Google AI Studio.

Sign up for a free cloud web service on Render.com or Railway.app, connect your GitHub repo, select Docker runtime, and deploy!

3

Enable GitHub Pages for Mobile Web App

Under your repository settings, navigate to Pages, set source to Deploy from a branch, and select main / frontend.

Open the generated GitHub Pages URL on your Android or iOS device and tap "Add to Home Screen" to turn JARVIS into a full-screen PWA app.

4

Connect Phone System Automation Tools

Android (Tasker): Create HTTP Request Tasks that listen for webhooks sent by the JARVIS FastAPI backend (e.g. /api/action) to toggle system settings, read SMS, or set native alarms.

iOS (Shortcuts): Use Apple Shortcuts with the "Get Contents of URL" action or trigger local URL schemes (shortcuts://run-shortcut?name=JARVIS_Alarm).

Configure Gemini API

Enter your Gemini API key for local web-based testing in the HUD. Your key is stored securely in your browser's local storage.
